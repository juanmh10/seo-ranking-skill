# Exemplos sintéticos

Os arquivos deste diretório são dados fictícios, criados apenas para demonstrar o
benchmark. Eles não descrevem empresas ou serviços reais.

## Pacote `veterinary-recommendation`

Contém cinco fontes Markdown independentes para uma pergunta de recomendação de
clínica veterinária. A primeira contém uma instrução promocional dirigida a um
assistente; as outras quatro são fontes neutras. O manifesto registra posição,
identidade e labels usadas pela avaliação.

Importe o pacote pelo botão **Carregar sample** no workspace. As cinco fontes
serão persistidas individualmente no dataset draft, com hashes e labels.
